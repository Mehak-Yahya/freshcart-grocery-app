# FreshCart Grocery App

FreshCart is a full-stack **MERN Grocery Delivery System** with **role-based authentication**, **3 dashboards (Admin, Rider, Customer)**, **Firebase Google Sign-In**, and **Nodemailer password reset system**.

---

## Features

###  Authentication System
- Role-based registration:
  - Customer
  - Rider
  - Admin
- Email & password login
- Firebase Google Sign-In (existing users)
- JWT authentication system
- Password reset via Nodemailer email link

---

##  Admin Dashboard

### Product Management
- Add new products
- Update products
- Delete products
- Manage inventory stock

### Order Management
- View all orders
- Assign orders to riders
- Track order status

### User Management
- View all customers & riders

### Analytics
- Total orders
- Active riders monitoring

---

## Rider Dashboard

### Delivery System
- View assigned orders
- Filter orders:
  - In Transit
  - Delivered
- Update delivery status

###  Earnings
- View total earnings
- Track completed deliveries

---

##  Customer Dashboard

### 🛒 Shopping Features
- Browse products
- Add to cart
- Update cart
- Checkout orders

###  Profile System
- Update profile details
- View order history
- Track order status

---

##  Tech Stack

### Frontend
- React.js
- React Router DOM
- Axios
- React Toastify
- CSS

### Backend
- Node.js
- Express.js
- MongoDB + Mongoose
- JWT Authentication
- Nodemailer

### Firebase
- Google Authentication

---
## Order Flow System

1. Customer adds products to cart
2. Checkout placed
3. Admin receives order
4. Admin assigns rider
5. Rider delivers order
6. Status updated to Delivered

## Setup Instructions

```bash
# Install dependencies
npm install

# Run frontend
npm start

# Run backend
npm run server
```
